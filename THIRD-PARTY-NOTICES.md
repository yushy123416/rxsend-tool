## Application icon

The application icon uses the SCP Foundation emblem, originally designed by
far2; the first high-resolution PNG version was created by Aelanna.
The vector reference used here is the 2023 Wikimedia Commons version.

## Counter-Strike share-code format

Counter-Strike share-code decoding uses the format documented by AkiVer's
csgo-sharecode project: https://github.com/akiver/csgo-sharecode
The decoder in this project is a C# implementation of that documented format.
