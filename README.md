## 功能特性

1. **回合状态与倒计时：** 同步服务器当前阶段、剩余回合与倒计时，结合 A2S 查询展示人数、地图和延迟；支持时间补偿。

2. **可自由编辑的悬浮计时：** 调整字体、字号、颜色、背景不透明度和圆角，在画布上拖动、缩放或隐藏各个组件。透明度只作用于背景，文字保持清晰；浮窗可独立下拉选服，也可跟随主界面。

3. **独立自动进服：** 勾选多个目标服务器，每 1 秒并行检测一次空位，发现空位后优先通过 Steam 启动参数发起一次连接并停止其他目标。支持取消和查询失败重试，与回合计时并行，切换页面不会中断任务。

4. **屏幕准星：** 支持当前 CS2、旧版 CSGO 与无畏契约主准星码导入，可调整形状、颜色、长度、粗细、间距、描边、缩放与偏移，选择显示器并保存预设。

5. **托盘与全局快捷键：** 主窗口默认关闭到托盘，准星鼠标穿透、不抢焦点；通过快捷键控制准星和计时浮窗，托盘可取消自动进服或退出程序。

6. **轻量原生界面：** 使用 C#、WinForms 和 GDI+，采用浅色 Fluent 风格，无 Electron、WebView 或浏览器运行时。

7. **NVIDIA 滤镜实验性配置：** 检测 NVIDIA 显卡、驱动和 NVIDIA App，自动寻找 Steam 库中的 GMod；为所选游戏程序尝试开启驱动许可，先备份原设置，并支持还原。

8. **广播模板：** 进入页面时自动拉取最新广播，优先 Gitee、失败时回退 GitHub，页面停留期间每 5 分钟检查一次。模板自动缓存到本地，离线时使用缓存，首次离线时使用内置的 8 条。直接展示正文，点击任意卡片即可复制，并在软件内短暂弹出“复制成功”提示。

9. **服务器信息：** 打开左侧“服务器信息”，独立选择服务器，查看服务器名称、人数、地图、游戏、回合状态、机器人数量和延迟，以及按本次在线时长降序排列的玩家列表。页面显示期间每 30 秒查询一次，切回已有服务器会复用缓存及剩余间隔；超时不会立即反复重试。在线时长是服务器返回的本次连接时长，非 Steam 累计游戏时间；未公开玩家列表时会显示提示，失败时保留上次成功的数据。


## 工作流程

```text
回合计时：选择服务器 → 同步回合状态 → 主界面 / 悬浮窗倒计时
                                 └→ 自定义字体、背景与组件布局

自动进服：选择目标服务器 → 开始监听空位 → 发现空位 → Steam 发起连接
                                      └→ 可随时取消

屏幕准星：导入准星码 → 实时预览与调整 → 选择显示器 → 开启准星
```

回合计时、自动进服与准星独立运行；NVIDIA 滤镜配置需要先退出游戏。

## 下载

程序启动后会自动检查更新，发现新版本后自动下载、校验并安装重启；失败时保留当前版本，可在“设置与更新”中查看原因并手动重试。

前往 [Releases](https://github.com/yushy123416/rxsend-tool/releases) 获取已发布版本。暂无发行版时，可以按下文从源码构建。

| 文件 | 用途 |
| --- | --- |
| `RXSendTool.exe` | 单文件程序，直接运行 |
| `RxToolbox-<版本号>-Windows.zip` | 程序与许可证的完整发布包 |

> 系统要求：Windows 10 / 11，.NET Framework 4.8。当前构建为 x86，可在 32 位和 64 位 Windows 上运行；自动进服需要 Steam 可用。

## 使用方法

### 回合计时与悬浮窗

1. 打开“回合计时”，在服务器列表中选择服务器。
2. 点击“开启悬浮计时”，将浮窗拖动到合适位置。
3. 点击“悬浮窗样式”，调整字体、各组件字号、颜色、背景不透明度、显隐与布局，保存后生效。
4. 点击浮窗名称旁的下拉箭头，独立选择服务器；也可以右键打开菜单，选择“跟随主界面选择”。

### 服务器信息

1. 打开左侧“服务器信息”，选择服务器并查看基本状态和玩家列表。
2. 页面显示期间每 30 秒刷新，切回已有服务器会沿用缓存和剩余刷新间隔。
3. 玩家列表按本次在线时长降序排列。

### 广播模板

1. 打开左侧“广播模板”，点击任意广播正文即可复制。
2. 复制后会显示短暂的“复制成功”动画提示，可直接粘贴到游戏中。
3. 进入页面时检查远端更新，停留期间每 5 分钟检查一次；离线时优先使用本地缓存，无缓存时使用内置模板。

### 自动进服

“服务器信息”的 30 秒刷新与自动进服独立。自动进服仍按每秒一次的间隔向各个目标发送 A2S_INFO，检测到空位后仅通过 Steam 发起一次连接；信息页每轮查询一次 A2S_INFO 和一次 A2S_PLAYER。A2S 挑战应答及响应分片可能增加实际 UDP 数据包数量。

1. 打开左侧“自动进服”，勾选一个或多个目标服务器。
2. 点击“开始自动进服”，程序在后台定时检测空位。
3. 发现空位后向 Steam 发送一次进服请求；等待期间可点击“取消自动进服”，或从托盘取消。


### 屏幕准星

1. 打开“屏幕准星”，粘贴 CS2、CSGO 或无畏契约准星码并导入。
2. 在预览区确认外观，调整参数、颜色、缩放和偏移。
3. 选择显示器并开启准星，需要时保存为预设。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + Alt + F8` | 显示 / 隐藏准星 |
| `Ctrl + Alt + F9` | 显示 / 隐藏回合悬浮窗 |

设置、浮窗布局和准星预设保存在 `%LOCALAPPDATA%\RxToolbox\settings.json`。

### NVIDIA 游戏滤镜（实验性）

1. 退出 GMod，打开左侧“NVIDIA 滤镜”，等待显卡、NVIDIA App 和游戏程序检测完成。未找到游戏时，可手动选择 `gmod.exe`、`gmod_win64.exe` 或旧版 `hl2.exe`。
2. 点击“尝试启用（实验性）”，在 Windows 提示中授权管理员权限。程序只对所选程序的 GMod 驱动配置进行操作，原设置保存在 `%LOCALAPPDATA%\RxToolbox\nvidia-gmod-backup.json`；已有备份时不会覆盖。
3. 在 NVIDIA App 中开启游戏内覆盖及“游戏滤镜和照片模式”，重启 GMod，按 `Alt + F3` 验证是否可用。切换游戏版本或程序前，先点击“还原原配置”。

此功能通过 NVIDIA NVAPI 尝试开启 Ansel 相关驱动许可。**配置写入并校验成功不代表游戏滤镜一定可用**：NVIDIA App 和驱动仍可能限制不支持的游戏。已在 RTX 5070 Laptop、驱动 621.14、NVIDIA App 11.0.9.585、GMod Build 25375506 上收到 RTX 动态亮丽及配置还原成功反馈，其他滤镜与版本组合仍未验证。当前实现不会修改 NVIDIA App 文件；如果仍提示“需要受支持的游戏”，此次兼容配置未能解除限制，可还原设置。NVIDIA 官方说明见[滤镜支持条件](https://nvidia.custhelp.com/app/answers/detail/a_id/5349)，驱动配置接口见 [NVIDIA NVAPI 源码](https://github.com/NVIDIA/nvapi)。

## 技术实现

- C#、WinForms 与 GDI+，基于 .NET Framework 4.8，使用 Windows 自带编译器构建。
- 通过 HTTPS 获取回合状态、广播模板及更新清单，通过 A2S 查询服务器与玩家信息，通过 Steam 协议发起进服。

## 从源码构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1 -Test
.\tests\UpdateSmoke.ps1
```

使用 Windows 自带的 .NET Framework C# 编译器，无需下载 .NET SDK 或 NuGet 包。程序输出到 `dist/RXSendTool.exe`，测试和中间产物位于 `build/`。



GitHub Actions 会构建、测试并创建草稿 Release，包含 EXE、发布压缩包和 `update.json`。审阅后发布正式 Release，旧版程序即可检查到更新；标签须与程序集版本一致。

程序优先从 [Gitee 镜像](https://gitee.com/ysyyyy/rxsend-tool) 获取更新清单与程序，失败时回退 GitHub。Gitee 自动拉取 GitHub 仓库中的 `updates/` 正式更新载荷，不依赖 Releases 附件同步。

需要手动生成清单时运行：

```powershell
.\publish-manifest.ps1
```

发布前更新 `src/Version.cs`，更新下方“更新日志”，再构建并生成清单。生成后将新版本的 `updates/` 与源码一并提交，再推送匹配的版本标签；CI 发布该目录中已校验的同一份 EXE，保证镜像与 GitHub 下载文件的 SHA-256 一致。不要复用旧版 EXE，也不要在生成清单后修改程序。

可在推送前本地验证最终发布载荷并生成 Release 文案：

```powershell
.\publish-manifest.ps1 -UsePrepared
.\tests\UpdateSmoke.ps1
.\release-notes.ps1 -Version 1.0.2
```

Release 文案生成到 `build/release-notes.md`。生成脚本直接提取本 README 中对应版本的更新日志。

广播模板维护在仓库的 `broadcasts/templates.json`，格式为正文字符串数组，无需标题。将文件推送到 GitHub 的 `main` 分支并同步 Gitee 后，程序即可拉取更新，无需重新发布 EXE。本地缓存位于 `%LOCALAPPDATA%\RxToolbox\broadcast-templates.json`。远端格式错误或下载失败时不会覆盖已有缓存。

## 常见问题


<details>
<summary><b>检测到空位，为什么仍未进入游戏？</b></summary>

自动进服只检测公开人数并向 Steam 发起连接，不会保留空位。Steam 状态、连接期间其他玩家加入，以及服务器验证或预留席位要求都会影响结果。“已向 Steam 发送进服请求”不代表已经进入服务器。

</details>

<details>
<summary><b>游戏里看不到准星或计时浮窗？</b></summary>

优先使用无边框窗口模式。独占全屏或游戏自身的叠加限制可能遮挡外置窗口；快捷键被占用时，可使用主界面或托盘操作。

</details>

<details>
<summary><b>导入准星后，为什么与游戏内不完全一致？</b></summary>

工具显示静态主准星，不模拟开火、移动扩散、后坐力或 ADS 切换。部分旧版尺寸及特殊形状为近似显示，可使用预览区继续调整。

</details>

<details>
<summary><b>检查更新提示“尚未发布可用更新”？</b></summary>

更新源需要正式 Release 中的 `update.json` 和 `RXSendTool.exe`。仅推送源码、创建标签或生成草稿还不够，需要发布 Release；同版本不会提示升级。

</details>

<details>
<summary><b>关闭窗口后，程序为什么还在运行？</b></summary>

默认关闭主窗口会留在系统托盘，浮窗与自动进服任务可以继续运行。需要完全退出时，右键托盘图标选择“退出”。

重复启动时，可在提示窗口点击“关闭上一个程序”，关闭旧实例并继续打开当前版本；旧实例的自动进服监听和悬浮窗会停止。点击“取消”则保留旧实例。

</details>

## 更新日志

### v1.0.2 · 2026-11-15

- 新增“服务器信息”页面：查看人数、地图、回合状态、延迟及玩家列表，按本次在线时长降序排列；每 30 秒刷新，查询失败时保留上次成功的数据；信息数值统一使用蓝色，暂无回合状态时显示“暂无”。

- 精简自动进服任务状态，显示运行时长；取消任务或发起连接后，计时停止并保留结果。

### v1.0.1 · 2026-11-13

- 新增 GMod NVIDIA 滤镜实验性配置：检测环境、备份原设置、启用及还原；明确已验证组合与兼容边界。

- 多格式准星导入、实时预览和预设保存。
